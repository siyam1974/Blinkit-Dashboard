# Blinkit sales dashboard

Interactive dashboard for the Blinkit grocery sales analysis: https://siyam1974.github.io/Blinkit-Dashboard/

It covers 8,523 product listings across 10 outlets, with filters for location tier, outlet size and type, product category, fat content and price tier. Click any bar to filter by it. Plain HTML and JavaScript, no dependencies.

The data cleaning, SQL queries and the script that generates `data.js` are in [blinkit-grocery-sales-analysis](https://github.com/siyam1974/blinkit-grocery-sales-analysis).
